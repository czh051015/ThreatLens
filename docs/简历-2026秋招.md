# 实习经历

**联软科技 · AI 开发实习生**（【实习起止年月】· 深圳）

**威胁攻击链分析智能 Agent（ThreatLens）**｜【项目起止年月】

项目描述：面向企业终端安全（EDR）威胁研判场景，构建具备事件归一化、攻击技术识别、攻击链还原与可解释证据链分析能力的威胁分析智能 Agent；基于实习期间积累的 MITRE ATT\&CK 框架与终端遥测检测链路认知，独立完成设计与搭建。

技术栈：Python、Pydantic v2（强类型事件 Schema + Field Validation）、DeepSeek API（LLM 集成）、pytest、Sigma 规则、MITRE ATT\&CK STIX、Mordor / Atomic Red Team 数据集

- 针对 Sysmon 遥测事件格式混杂（Windows 原生 / Elastic ECS 双变体）导致下游分析无法直接消费的问题，以 **Pydantic v2 强类型 Schema（Field Validation）** 设计统一事件契约（10 核心字段 + `event_uid` 唯一标识）并实现双格式兼容归一化，字段类型/时间格式/唯一性在加载期强制校验，在 9050 条真实攻击事件上 100% 无损转换、`event_uid` 跨数据集唯一性 0 冲突。
- 针对纯规则匹配精度偏低（规则泛化导致误报）的问题，构建确定性规则主干（2815 条 Sigma 规则按 EventID 预索引 + ATT\&CK 字典归一化），并设计 **LLM 三介入点架构**（低分证据复核 + 冲突证据裁决），LLM 仅在规则主干判定完成后的低置信命中上介入，攻击链识别 precision 由 36.4% 提升至 57.1%（+20.8pp），recall 100% 全程保持。
- 针对评测结果易被自定义规则与测试集结论污染（循环论证）的问题，设计版本分离评测（官方规则版 vs 官方+自定义版分别报告）与 prompt"防背答案"红线，同一命令连跑两遍输出逐字节一致，全部指标可复现、可辩护。
- 针对攻击链结果不可解释、证据无法回溯的问题，实现 `event_uid` 证据链与 LLM 裁决审计日志：链上全部 34 条证据经 `event_uid` 反查原始事件 **100% 成功**、金标技术 **0 误剔**，LLM 每次复核/裁决的输入输出均落审计日志，可复现、可审计、可人工核对。

> 说明：该项目为实习期间基于领域认知**独立搭建的个人原型**（非公司交付任务），评测全部使用公开数据集（Mordor 真实攻击录制 + Atomic Red Team 金标），仓库含完整开发说明书与决策记录。
